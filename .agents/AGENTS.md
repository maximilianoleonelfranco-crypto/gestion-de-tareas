# Reglas del Proyecto: Gestor de Tareas

- **Sincronización Web (Vercel):** Cada vez que se haga un cambio en el código fuente de la aplicación, se debe ejecutar el siguiente comando para subir los cambios a GitHub y que Vercel los detecte y publique automáticamente:
  `git add . ; git commit -m "Auto-update" ; git push`
